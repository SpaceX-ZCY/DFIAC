# DFIAC
我的这个DFIAC模型

## Datasets

DFIAC-Net was evaluated on three public remote sensing change detection datasets.

### LEVIR-CD256

- Download the preprocessed 256 × 256 version from the [ChangeFormer repository](https://github.com/wgcban/ChangeFormer#links-to-processed-datsets-used-for-trainvaltest).

### WHU-CD

- Download the [WHU-CD dataset on Baidu AI Studio](https://aistudio.baidu.com/datasetdetail/251669) using the link listed in the [DCSI-UNet repository](https://github.com/ZChaoyv/DCSI-UNet).

### SYSU-CD

- Download the dataset from the [original SYSU-CD repository](https://github.com/liumency/SYSU-CD#download), which lists Baidu Netdisk and OneDrive links.
